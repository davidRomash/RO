# RO

Roblox game synced with [Rojo](https://rojo.space).

## Connect to Roblox Studio
1. Install Roblox Studio and Rojo: `aftman install` (or download Rojo from its GitHub releases).
2. Install the Rojo plugin in Studio (Creator Store: "Rojo").
3. In this folder run: `rojo serve`
4. In Studio, open the Rojo plugin tab and click **Connect**.
5. Press Play — you should see a "Coins" leaderboard and a welcome message in Output.
