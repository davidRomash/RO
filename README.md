# Animal Rush

A Roblox collect-and-race game: hatch animals, race them on zone tracks, use each animal's
ability where it fits best. This is the MVP from the design document: Plaza hub, Forest and
Beach zones, 10 animals, 2 tracks, eggs, 8 bases, daily reward and a leaderboard.

## Run it in Roblox Studio

1. Install Rojo 7.7.0 (`aftman install`, or download it from the Rojo GitHub releases) and the
   Rojo plugin in Studio.
2. In this folder run `rojo serve`, then click **Connect** in the Rojo plugin.
3. Press **Play**. The whole map is built by the server when the game starts, so it only
   appears while playing, not in edit mode.

To save progress while testing in Studio: publish the place, then turn on
**Game Settings > Security > Enable Studio Access to API Services**. Without it the game still
works, but data resets every session.

## How the code is organised

| Where | What |
|---|---|
| `src/config` | All balance numbers: animals, rarities, eggs and odds, zones and tracks, economy, sounds. Tune the game here. |
| `src/shared` | Code used by both sides: world positions (`Layout`), pet stats (`PetMath`), placeholder animal models (`AnimalModel`). |
| `src/server/Services` | Everything that matters is decided here: saving (`DataService`, using ProfileStore), racing, eggs, pets, zones, bases, rewards, tutorial, world building. |
| `src/client/Controllers` | HUD, menus, hatch animation, race display, guide arrow, pets following players. |
| `default.project.json` | Rojo mapping plus every RemoteEvent / RemoteFunction. |

## Placeholders to replace

- **Animals** are built from simple shapes in `src/shared/AnimalModel.luau`. To use real models,
  put them in ReplicatedStorage and make `AnimalModel.Build` return a clone.
- **Sounds** are empty in `src/config/Sounds.luau`. Add free sound ids from the Creator Store.
- **The map** is generated by `src/server/Services/WorldBuilder.luau` from parts.

## Admin commands

Open the red 🛠️ button on the right of the screen, or type in chat (only the game owner, people listed in `src/config/Admins.luau`, and anyone in Studio):
`;help`, `;coins 1000`, `;setcoins 0`, `;pet shark golden`, `;unlock all`, `;tp beach`,
`;speed 50`, `;base 3`, `;skiptutorial`, `;reset`. Add a player name at the end to target
someone else, or `all` for everyone.
